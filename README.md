# WPS CSO Coalition Mongolia — Bilingual Website

Open `index.html` in a web browser to preview. The logo is supplied as `wps-logo.png`; keep both files together.

## Publish free on GitHub Pages
1. Create a GitHub account and a public repository.
2. Upload `index.html` and `wps-logo.png` in the repository root.
3. Under Settings → Pages, select Deploy from a branch, `main`, root.
4. Save and wait for the GitHub Pages URL.

Site contact details are taken from the email signature provided by the coalition representative. Mission, vision and program areas are still marked as proposed and should be aligned with any approved organization documents. The site has NOT yet been deployed.
